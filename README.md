# caiguwang-creator
才谷网投票是才谷网（chinacaigu.com）旗下的 AI 投票制作技能——10年品牌、超亿人使用、全免费的共享投票小程序。当用户需要制作投票、发起评选、组织投票活动、创建微信投票时使用此 Skill。支持群投票、图文投票、分组投票制作，投票模板精美，稳定可靠，安全防刷!核心功能：1. 投票模板检索——按关键词筛选，返回模板列表与预览图 2. AI 一句话创建投票——描述需求即可生成标题、投票时间、投票规则并匹配模板 3. 批量添加选手——JSON 批量导入选手名称与图片，支持分组 4. 活动修改——对话修改标题、说明、时间、投票规则、分组，支持分组改名 5. 图片上传——本地图片转 URL 并进入素材库 6. 数据查询——选手票数榜单、参与人数、累计投票、浏览次数。
